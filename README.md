## 📖 Overview

This repository contains **MATLAB simulation codes, lab reports, and assignment files** for the **Data Communication Lab** course of **Jagannath University (JnU) - CSE Department**.

The purpose of this repository is to help students understand **Data Communication concepts practically through MATLAB simulations and visualizations**.

Each lab includes:

✅ MATLAB Simulation Code (`.m`)  
✅ Lab Report (`.pdf`)  
✅ Assignment Questions  
✅ Signal Visualization & Graphical Output  

By running the MATLAB codes, students can **easily visualize signals, communication techniques, waveform behavior, and simulation outputs**.

# 🚀 How to Run the MATLAB Code

## Step 1: Clone the Repository

```bash
git clone https://github.com/your-github-username/data_communication_lab_JnU_CSE.git
```

---

## Step 2: Open MATLAB

Launch **MATLAB** on your computer.

---

## Step 3: Open Repository Folder

Navigate to the downloaded repository folder.

Example:

```matlab
cd 'your-folder-path/data_communication_lab_JnU_CSE'
```

---

## Step 4: Run Any Lab File

Open any `.m` file and click **Run**.

Example:

```matlab
datacom_lab1
```

Or,

```matlab
run('datacom_lab1.m')
```
