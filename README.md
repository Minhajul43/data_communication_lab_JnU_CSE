# 📡 Data Communication Lab - JnU CSE

Welcome to the **Data Communication Lab Repository** for **Jagannath University (JnU) CSE Department**.

This repository contains **MATLAB codes (`.m`)**, **lab assignments**, and **PDF reports** for the **Data Communication Lab** course. The main goal of this repository is to help students understand the practical implementation and simulation of Data Communication concepts using **MATLAB**.

---

## 📂 Repository Structure

This repository is organized lab-wise. Each lab contains:

- **MATLAB Source Code (`.m`)** → Used for simulation and implementation.
- **Lab Report / Output PDF (`.pdf`)** → Contains explanation, results, and outputs.
- **Assignment File** → Lab assignment questions and requirements.
